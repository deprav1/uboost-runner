# ЮБуст Раннер — Style Guide для генерации ассетов

Этот файл — единый источник истины по бренду. Используй его при генерации
изображений любым инструментом (Midjourney, Flux, DALL·E, SDXL, Stable Diffusion).

---

## Палитра

| Роль           | HEX       | Где                                      |
|----------------|-----------|------------------------------------------|
| Фон            | `#000000` | Всегда чёрный или очень тёмный `#0a0204` |
| Акцент-красный | `#ff2937` | Glow, рамки, элементы опасности           |
| Ярко-красный   | `#ff5a64` | Светлые акценты, hover-состояния          |
| Тёмно-красный  | `#7d0f18` | Тени, объём                               |
| Белый          | `#ffffff` | Основной контентный цвет, текст           |
| Серый          | `#c9ced6` | Второстепенный текст                      |

> Никаких градиентов cyan/magenta/жёлтых акцентов — это был старый стиль. Только чёрный + красный + белый.

---

## Вайб и стиль

- **Флэт-вектор / неон-стикер**: плоские формы, жирные контуры (stroke), светящийся glow.
- **Эмоция**: мемная сатира на рунет — капчи, блокировки, казино, упавшие сервисы. Легко, не злобно.
- **Никакого реализма**: пикселе-арт, флэт-иконки или векторные стикеры.
- **Прозрачный фон**: все PNG с `alpha=0` на фоне (кроме `world/*` — там тёмный полупрозрачный).
- **Glow-эффект**: элементы должны иметь красное свечение (~10–20px) — имитирует неон в игре.

## Общий prompt-префикс

```
flat vector neon sticker, black background, red glowing outline #ff2937,
white and red color scheme, no gradients except neon glow, pixel-clean edges,
transparent background, game asset sprite --no photorealism --no 3d --no shadow
```

---

## Do / Don't

| ✅ Do                                          | ❌ Don't                                    |
|-----------------------------------------------|---------------------------------------------|
| Чёрный фон или прозрачный                      | Белый или серый фон                         |
| Красные и белые цвета                          | Синий, зелёный, жёлтый как основные         |
| Флэт, жирный stroke, неон-glow                 | Фото-реализм, 3D-рендер                     |
| Мемный / саркастический стиль                  | Официальные логотипы брендов 1:1            |
| Прозрачный PNG                                 | JPG или непрозрачный фон                    |
| Читаемые, чёткие формы (48px+ видны)           | Мелкие детали < 12px                        |

## Размеры экспорта

| Категория       | Размер (px) | Прозрачность |
|-----------------|-------------|--------------|
| obstacles/*     | 256×256     | Да           |
| world/skyline   | 1024×256    | Нет (тёмный) |
| world/core      | 512×512     | Да           |
| world/tower_*   | 64–96×256–320 | Да          |
| minigame/*      | 128×128     | Да           |
| gags/*          | 128–256×128 | Да           |

## Файловая структура

```
assets/
  obstacles/   captcha.png  geoblock.png  ad.png  lag.png
  world/       skyline.png  core.png  tower_a.png  tower_b.png
  minigame/    traffic_light.png  bus.png  hydrant.png
               storefront.png  motorcycle.png  taxi.png  decoy_frame.png
  gags/        heart.png  sber_down.png  rkn_badge.png  ad_popup.png  combo_burst.png
  manifest.json
  STYLE_GUIDE.md  (этот файл)
  PROMPTS.md
```

Если файла нет — игра автоматически рисует процедурно. Кладёшь PNG → подхватывается сразу.
