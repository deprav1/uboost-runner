# Problem
При добавлении 3D-детализации маскота (градиенты, блики) игра начала сильно тормозить (падение FPS).

# Root Cause
При использовании Canvas 2D API свойство `ctx.shadowBlur` (особенно с большими значениями, например `36`) является крайне ресурсоемким. В коде тень включалась для внешнего свечения куба, но **не отключалась** перед отрисовкой внутренних деталей:
1. Вызова `ctx.clip()`
2. Отрисовки трех граней с `createLinearGradient`
3. Отрисовки линий стыков (`ctx.stroke()`)

Браузер пытался просчитать 36-пиксельное размытие тени для *каждой* внутренней фигуры и заливки, что приводило к экспоненциальному росту нагрузки на GPU/CPU и падению FPS.

# Solution
Применять тень хирургически только к базовой подложке, а затем принудительно отключать перед сложными заливками:
```javascript
// 1. Рисуем контур (маску) и заливаем, чтобы отбросить ОДНУ общую тень
ctx.shadowColor = glow;
ctx.shadowBlur = 36;
ctx.fillStyle = C.red; // цвет не важен, он будет перекрыт
ctx.fill();

// 2. ОТКЛЮЧАЕМ ТЕНЬ перед внутренними деталями!
ctx.shadowColor = 'transparent';
ctx.shadowBlur = 0;

// 3. Только теперь клипаем и рисуем тяжелые градиенты
ctx.clip();
// ... gradient fills
```

# Prevention
Всегда сбрасывать `ctx.shadowColor = 'transparent'` и `shadowBlur = 0` перед `ctx.clip()` или перед множественными `fill()` / `stroke()`, если тень нужна только для внешнего силуэта. Тень должна применяться к одной сплошной фигуре, а не к набору составных частей.
