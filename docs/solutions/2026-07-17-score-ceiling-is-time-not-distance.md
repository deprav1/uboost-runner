# Честный забег терял приз: потолок очков был привязан к дистанции, а не ко времени

## Problem
Топовый забег на боевой доске — **10 181 очко за 291 м** — висел с `verified=0`,
то есть выпадал из розыгрыша (`notify-winners` раздаёт призы только по
`verified=1`). Выглядело как накрутка: 35 очк/м против 17–22 очк/м у остальных.

Накруткой это не было. Забег честный, а отклонил его **неверный лимит на сервере**.

Рядом пряталась вторая мина: тот же забег подходил к сквозному потолку
`SCORE_BASE_ALLOWANCE + distance * MAX_SCORE_PER_METER` на **79%**. Игрок чуть
сильнее получил бы `422 implausible` и потерял бы результат целиком — не только
бейдж, а весь забег.

## Root Cause
Модель правдоподобия была неверна в корне: **очки ограничивались дистанцией**
(`dScore <= dDist * 40 + 600`), хотя очки набегают **с колонн**, а колонны
приходят **по времени** (`colSpacing / speed`), и на них действуют множители.

Физический потолок, посчитанный из `config.js`:

```
одна колонна при X2 и комбо 8:
  near-miss  SCORE_NEAR_MISS(25) * min(combo,8) * X2_MULT(2) = 400
  биты       BITS_PER_COL(4) * SCORE_BIT(15) * 3 * X2_MULT(2) = 360
  dodge      SCORE_PER_DODGE(10) * 2 * X2_MULT(2)             =  40
                                                        итого = 800 очков
колонна не чаще REACT_TIME = 0.42 с  =>  ~1905 очк/с
на минимальном интервале (330 px = 6.6 м)  =>  ~121 очк/м
```

То есть **121 очк/м законны**, а лимит стоял на **40**. Разбор реального забега
по heartbeat-сессии:

```
последняя отметка : 5160 очк / 223 м
финал             : 10181 очк / 291 м
хвост             : +5021 очка за 68 м = 74 очк/м   (вдвое НИЖЕ потолка 121)
лимит             : 68*40 + 600 + 900 = 4220        -> 5021 > 4220 -> verified=0
```

Игрок словил X2 и цепочку near-miss на плотном участке — ровно тот геймплей,
который игра поощряет, — и именно за это потерял приз. Бьёт по тем, кто играет
лучше всех, то есть по единственным претендентам на награду.

## Solution
Очки ограничены **временем**, как и дистанция ([server.js](../../backend/server.js)):

```js
const MAX_SCORE_PER_SEC = 2000;   // физический максимум ~1905
function plausibleDelta(dScore, dDist, dtSec, extra = 0) {
  if (dScore < 0 || dDist < 0) return false;
  if (dDist > (dtSec + 2) * MAX_METERS_PER_SEC) return false;
  return dScore <= (dtSec + 2) * MAX_SCORE_PER_SEC + extra;
}
```

Это строже как анти-чит и честнее к игроку одновременно: **больше физически
возможного за секунду не начислить, а время подделать нельзя** — его наблюдает
heartbeat-сессия. Потолок теперь совпадает с идеальной игрой, а не с догадкой.

`MAX_SCORE_PER_METER` 40 → **130** (выше физических 121) — остаётся только
сквозным грубым фильтром против наглого curl, а не рабочим ограничением.

Проверено на точных числах отклонённого забега:

| сценарий | результат |
|---|---|
| реальный забег tg:41515897 (+5021 / 68 м) | verified=1 |
| всплеск X2+комбо на пределе (~1900 очк/с) | verified=1 |
| выше физического потолка очк/с | ОТКЛОНЁН (implausible) |
| миллион в хвосте | ОТКЛОНЁН (implausible) |
| накрутка в середине забега (+50k за 5 с) | 422 |

## Prevention
- **Любая величина «за метр» в анти-чите — ошибка.** Метры в этой игре суть
  время (`distance += speed*dt*0.02`), а очки идут с колонн по временной
  каденции. Ограничивать надо время; дистанция — производная.
- **Не подбирать пороги «на глаз» по наблюдаемым забегам.** 40 очк/м выглядело
  щедро на фоне живых 17–22 очк/м — и было втрое ниже физически возможного.
  Потолок надо **считать** из `config.js`: множители (X2 ×2, комбо ×8, биты ×3)
  перемножаются и дают всплеск, которого в «средних» данных не видно.
- Тест в `harness.mjs` считает физический максимум из `CONFIG` и падает, если
  `MAX_SCORE_PER_SEC`/`MAX_SCORE_PER_METER` его не покрывают. Поэтому новый
  множитель или пикап (сильнее X2, комбо выше 8, больше битов в колонне)
  автоматически уронит тест, а не молча отнимет приз у лучшего игрока.
- **Симптом «верхний забег доски не verified» — сначала проверять свой лимит,
  а не подозревать игрока.** Разбор heartbeat-сессии (`run_sessions`:
  `last_score`, `last_distance`, `beats`) сразу показывает, на чём отвалилось.
