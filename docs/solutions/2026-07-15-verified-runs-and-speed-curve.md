# Честный забег терял verified + кривая скорости, рассчитанная на 15-минутный забег

## Problem
Два независимых дефекта, найденных при аудите живого сервера (31.130.148.55):

1. **Верификация.** Честный забег мог получить `verified=0` и молча выпасть из
   розыгрыша: призы раздаются только по `verified=1`
   ([notify-winners.mjs](../../backend/notify-winners.mjs) фильтрует `WHERE r.verified = 1`).
   Бил он именно по высокоочковым забегам — то есть по претендентам на приз.
2. **Баланс.** Игра почти не разгонялась там, где происходит вся игра. При
   `SPEED_GROWTH: 5` плато `MAX_SPEED` достигалось на **11 600 м ≈ 15 минут**
   непрерывного забега. Реальные забеги на доске жили в 150–400 м, где скорость
   успевала вырасти на 5% (360 → 380 px/с), а время на реакцию стояло на 0.86–0.91 с.
   Даже через 5 минут игры скорость была всего 486 px/с. Забег заканчивался скукой,
   а не стеной.

Плюс: значок `verified` доходил до клиента и нормализовался
([leaderboard.js](../../src/game/leaderboard.js)), но **не отрисовывался нигде** —
правило призов было для игрока невидимым.

## Root Cause

**1. Верификация.** Бонус миссий начисляется одним скачком на game over
([main.js](../../src/main.js) `stats.score += bonus`) — **после** последней
heartbeat-отметки, которая шлёт `stats.scoreInt` без бонуса. Сервер сверял финал
лимитом `dScore <= dDist * 40 + 600`. Дистанция в этом окне не растёт (в капче она
вообще заморожена), поэтому лимит вырождался в жёсткие `600`, а скачок доходил до
**850** = бонус 3 лучших миссий (200+150+150) + `SCORE_CAPTCHA_SOLVE` (350).
Воспроизведено на локальном сервере: смерть в концовке капчи → `verified=0`.

**2. Баланс.** `MAX_SPEED`/`DIFF_DIST` задавались в «метрах» без учёта того, что
метры жёстко связаны с секундами: `distance += speed * dt * 0.02`
([stats.js](../../src/game/stats.js)) ⇒ м/с = скорость_px × 0.02. Константы
подбирались на глаз, а не интегрированием `dd/dt = baseSpeed(d) * 0.02`, и молча
уехали на порядок. Побочный эффект: `colSpacing = max(330, speed * REACT_TIME)` —
второе слагаемое перехватывало только со скорости 785 px/с, т.е. с **8500 м**,
поэтому заявленная в комментариях «честность коридора через REACT_TIME» на практике
не включалась никогда: всё правила константа `COL_SPACING_MIN`.

## Solution

**Верификация** ([server.js](../../backend/server.js)):
- `END_BONUS_ALLOWANCE = 900` — допуск, покрывающий разовые бонусы, которые
  приходят после последней отметки без пробега.
- `plausibleDelta(..., extra = 0)` — допуск даётся **только** финальной сверке и
  один раз за забег. На `/v1/run/beat` лимит остался тугим, иначе читер накручивал
  бы по +900 на каждой отметке. Сквозной потолок
  `score <= SCORE_BASE_ALLOWANCE + distance * 40` продолжает действовать.
- Проверено: честные сценарии → `verified=1`; читер на +1600 → `verified=0`;
  +10k/+100k/+1M → `implausible`; накрутка в середине забега → 422.

**Кривая** ([config.js](../../config.js), [main.js](../../src/main.js)):
- `SPEED_GROWTH: 5 → 32` — плато приходит на ~1810 м ≈ 2.5 мин.
- `DIFF_DIST: 2600 → 1200` — пик плотности (≈1:50) **раньше** плато скорости:
  два пика не складываются в один момент, сначала плотность, потом скорость.
- `WAVE_PERIOD: 900 → 450` — период волны укладывается в забег.
- Creep отсчитывается от **плато**, а не от `DIFF_DIST`: плато выводится из
  констант (`SPEED_PLATEAU_DIST`), иначе множитель разгонял бы ещё растущую базу.
- Целевая длина забега зафиксирована комментарием в `config.js`: новичок ~20–30 с
  (150–240 м), освоившийся ~45–90 с, потолок ~2.5 мин.

**Доска** ([screens.js](../../src/ui/screens.js), [strings.js](../../src/ui/strings.js)):
- Значок `✓` (`--ok`, зелень зоны «Даркнет») рядом с `✈`: подтверждён + куда писать.
- Строка правила призов под доской, только на общей доске.
- `qTopTotal` отдаёт `MIN(r.verified)` — «весь пробег наблюдался», т.к. призы по
  этой доске суммируют только `verified=1`.
- Заголовок доски больше не дублирует строку статуса (оба выводили `leaderboardGlobal`).

## Prevention
- **Кривую проверять интегрированием, а не на глаз.** В `harness.mjs` добавлен тест:
  плато достижимо за 60–240 с, `DIFF_DIST` раньше плато, `WAVE_PERIOD` ≤ `DIFF_DIST`.
  Откат `SPEED_GROWTH` к 5 уронит тест.
- **Любой новый разовый бонус, начисляемый на game over, ломает верификацию**, если
  не влезает в `END_BONUS_ALLOWANCE`. Тест в `harness.mjs` связывает `CONFIG.MISSIONS`
  + `SCORE_CAPTCHA_SOLVE` с константой сервера: добавишь жирную миссию — упадёт.
- Допуск давать только финальной сверке; на отметках лимит тугой.
- Значки доски покрыты тестом (`showDashboard` с синтетической доской): verified
  получает `✓`, неподтверждённый — нет, правило призов не показывается на локальной.
- `verified=0` у старых забегов на VPS — это наследие до деплоя heartbeat, а не баг.
  Прежде чем чинить верификацию, сверять `runs.created_at` с датой деплоя.
