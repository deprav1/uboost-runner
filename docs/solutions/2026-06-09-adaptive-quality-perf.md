# Тормоза на хостинге → адаптивное качество рендера

## Problem
Игра ощутимо лагала на GitHub Pages, особенно в мобильном Telegram WebView.
На десктопе плавно, на телефоне — просадки fps.

## Root Cause
Каждый кадр выполнялась тяжёлая полнокадровая пост-обработка поверх canvas с очень
высоким разрешением:
1. **DPR до 2.5** (`setupCanvas`): на телефоне это ×6.25 пикселей — огромный fill-rate.
2. **`aberration`** ([postfx.js](../../src/engine/postfx.js)) — **два** прохода всего
   кадра через `ctx.filter` (brightness/contrast) + `multiply`-заливки + композит.
   Самый дорогой эффект, гонялся каждый кадр.
3. **`bloom`** — `ctx.filter: blur(...)` по уменьшенной копии всего кадра (CSS-blur
   дорог на мобиле), масштаб буфера тянулся за DPR.
4. **`grain`** — тайлинг 256-шумовой текстуры по всему экрану с `overlay`-блендом.
5. **`shadowBlur`** на ~37 штрихах сетки-пола каждый кадр (`world._drawFloor`) —
   размытие штрихов крайне затратно на мобильных GPU.

Сумма: высокий DPR × несколько full-frame фильтр-проходов = мобильный webview не тянет.

## Solution
**Адаптивное качество** — менеджер следит за временем кадра и сам подбирает тир,
сохраняя синтвейв-стиль (деградирует мягко):
- Новый [quality.js](../../src/engine/quality.js): EMA времени кадра; тиры 0–3
  задают `dpr`, вкл/выкл `bloom/aberration/grain/scanlines` и `bloomScale`. Понижает
  тир при среднем кадре > `DOWN_MS`, повышает при < `UP_MS` (гистерезис + cooldown,
  чтобы не дёргалось). Параметры — в `CONFIG.QUALITY`.
- [render.js](../../src/engine/render.js) `setupCanvas(canvas, dprCap)` — потолок DPR
  по умолчанию **2** (вместо 2.5), и `setDprCap()` меняет его на лету (тир ↓ → DPR ↓).
- [main.js](../../src/main.js): `quality.sample(dtMs)` каждый кадр; пост-эффекты
  гейтятся `quality.s` (aberration — только ультра; grain/scanlines/bloom — по тиру).
  Виньетка дёшева — всегда.
- **`aberration` по умолчанию выключена** (тир 2), включается лишь на сильном железе.
- [world.js](../../src/game/world.js): убран `shadowBlur` с сетки-пола — свечение даёт
  пост-bloom (на потато-тире сетка просто плоская). Минус ~37 размытых штрихов/кадр.

Итог: на слабых устройствах автоматически DPR 1.25–1.5 без aberration/grain (и без
bloom на дне), на мощных — полный ультра-вид. Один билд работает и на ПК, и на мобиле.

## Prevention
- Полнокадровые эффекты с `ctx.filter`/`shadowBlur` — самые дорогие; новые такие
  эффекты добавлять **через тир качества**, а не безусловно.
- DPR на мобиле всегда ограничивать (×2 уже даёт ×4 пикселей).
- `shadowBlur` в горячих циклах (много штрихов/кадр) избегать — полагаться на bloom.
- Тюнинг порогов/тиров — только в `CONFIG.QUALITY`. Превью (`render-shot.mjs`) рендерят
  в полном качестве (`CONFIG.FX` напрямую) — это эталон «ультра», не трогать.
