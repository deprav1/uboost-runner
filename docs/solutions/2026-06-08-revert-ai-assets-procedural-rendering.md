# Problem
Интеграция растровых AI-спрайтов нарушила архитектурную концепцию игры, которая опирается исключительно на процедурный Canvas-рендеринг для стабильности, малого веса проекта и стилистического единства.

# Root Cause
Ассистент по запросу сгенерировал 14 растровых PNG-спрайтов, поместил их в каталог `assets/` и активировал вызов `loadAssets()` в `src/main.js`. Это шло вразрез со стратегическим решением проекта (зафиксированным в `CLAUDE.md`), согласно которому процедурный рендеринг является основным визуальным решением для обеспечения максимальной надёжности и независимости от сторонних графических ресурсов.

# Solution
Проведен полный откат (revert) коммита `a850b80cb231251f289fbdfe70d7ead3953014b6`, удалены растровые ассеты, а вызов `loadAssets()` в `src/main.js` возвращен в закомментированное состояние. Проект снова полностью использует процедурный рендеринг. Все тесты (`npm test`) и генерация скриншотов (`npm run shots`) проходят успешно.

# Prevention
Перед внесением изменений в структуру визуальных ресурсов или генерацией ассетов всегда сверяться с `CLAUDE.md`, историей коммитов и существующими архитектурными решениями. Развивать визуальную составляющую исключительно в рамках процедурного Canvas-рендеринга (`src/engine/render.js` и соответствующие файлы классов).
