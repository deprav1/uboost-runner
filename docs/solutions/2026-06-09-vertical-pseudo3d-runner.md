# Переориентация на псевдо-3D раннер «в город»

## Problem
Геймплей шёл вбок (горизонтальный раннер): объекты ехали справа-налево, игрок менял
полосу по вертикали. Это не стыковалось с фоном — сетка-пол и солнце уходят в точку
схода «вглубь», а движение было поперёк. Нужно: камера смотрит вдоль дороги на
город, куб-маскот у низа, объекты налетают из глубины, мемы проносятся мимо.

## Root Cause
Пространственная модель была экранной: у объектов был `.x` (горизонталь),
`o.x -= speed*dt`; игрок фиксирован по `x = geom.playerX`, полоса = `y = laneY[lane]`;
коллизии — экранный AABB (`overlap()`). Ось движения была перпендикулярна перспективе
фона.

## Solution
Поворот оси на 90° в **псевдо-3D**. Введена глубина `z` (1 = горизонт, 0 = камера):
- **`geometry().project(laneNorm, z) → {x, y, scale}`** ([world.js](../../src/game/world.js)) —
  единая проекция. `p = 1−z`; `y = horizon + (H−horizon)·p²` (та же кривая, что у
  горизонталей пола); полосы сходятся к точке схода; `scale` растёт к камере. Тюнинг —
  в `CONFIG.RUN` ([config.js](../../config.js)).
- **Объекты** (Obstacle/DataBit/Heart/Boost) живут в `(lane, z)`: `z -= speed·dt·Z_RATE`,
  спавн при `z≈1`, отрисовка через `project()` со `scale`. Экранный `hitbox` убран.
- **Коллизии** в `(lane, z)`: попадание при `|z−playerZ|<Z_HIT && |laneNorm−playerLane|<LANE_HIT`;
  уклонение когда `z` ушёл за игрока ([main.js](../../src/main.js) `handleCollisions`).
- **Отрисовка far→near** (painter's): все объекты+биллборды в один список, сортировка
  по `z` убыв., игрок вставляется на своей глубине.
- **Ввод** ([input.js](../../src/engine/input.js)): ось влево/вправо (свайп `dx`,
  тап-половины по `x`, клавиши ←→/A D/Ф В) → `player.left()/right()`.
- **Игрок** ([player.js](../../src/game/player.js)): `laneFloat`-твин, позиция из
  `project(laneNormF, PLAYER_Z)`, крен при смене колонны, выхлоп **вниз на камеру**
  (`particles.thruster(..., 0, 1)`). **Отрисовка куба-маскота не изменена** (требование).
- **Скорость**: горизонтальные спид-лайны заменены радиальными `zoomlines()` от точки
  схода ([render.js](../../src/engine/render.js)); `drawRails` рисует треки полос вдоль
  колонн к VP.
- **Мемы**: новый слой [billboards.js](../../src/game/billboards.js) — мем-щиты на
  обочинах (`laneNorm = ±SHOULDER`), рождаются у горизонта и проносятся мимо. Гэг-
  оверлеи (`events.js`) сохранены как были.

## Prevention
- Любая позиция в мире — через `geom.project(laneNorm, z)`; **не считать экранные
  координаты вручную** и не возвращать AABB-хитбоксы — коллизии в `(lane, z)`.
- Все параметры перспективы — в `CONFIG.RUN`, не хардкодить.
- Риск «туннелирования» сквозь зону `Z_HIT` на BOOST_SPEED при крупном `dt` гасится
  неуязвимостью во время буста; для обычной скорости `dz < 2·Z_HIT` при dt≤0.05.
- `test/render-shot.mjs` расставляет объекты по `z` и рисует far→near — держать
  синхронным с `main.js`. Инвариант коридора (`nextSafeLane`, ±1) не зависит от модели
  и остаётся в силе.
