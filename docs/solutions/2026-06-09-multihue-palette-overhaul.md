# Кардинальный визуальный overhaul: мульти-хью палитра

## Problem
Графика выглядела «убого»: вся сцена — небо, солнце, сетка-пол, горы, дымка, игрок,
ВСЕ препятствия, биты, сердца, спид-лайны и bloom — была нарисована одним красным
(`#ff2937` и оттенки) на чёрном. Нет цветовой иерархии → геймплейные объекты
сливались с фоном, глаз уставал, композиция «солнце+красная сетка» читалась как
бесплатный шаблон. Дополнительно: плитки капчи были пустыми квадратами (тофу □).

## Root Cause
1. **Монохром.** `CONFIG.COLORS` на ~90% состоял из красных хексов; код берёт цвета
   из этих ключей, поэтому весь рендер был одного хью.
2. **Тофу капчи.** Иконки плиток рисовались эмодзи через `font:'system-ui'`
   (`captcha.js`). В Telegram WebView и офлайн-рендере `@napi-rs/canvas` нет
   эмодзи-шрифта → пустые квадраты.
3. **Конфликт спрайтов.** AI-PNG в `assets/` были красно-тематические и при загрузке
   в браузере перекрывали процедурку → ломали новую палитру (live ≠ preview).

## Solution
Принцип **«цвет = смысл»** (мульти-хью синтвейв), брендовый красный — только у игрока,
бустов и CTA:
- **Палитра** (`config.js`): холодное небо (фиолет→маджента→индиго), **циан**-сетка/
  рельсы/спид-лайны/рим-лайт гор, **закатное** солнце (золото→оранж→маджента),
  семантические ключи `data` (биты, циан), `heart` (розово-красный), `warn` (янтарь,
  опасность). Старые ключи не переименованы — только значения.
- **Фон** (`world.js`): новый градиент неба, опц. слой туманностей `FX.NEBULA`,
  перспективное затухание сетки (дальние линии — тусклый индиго, ближние — яркий циан).
- **Объекты**: биты → циан, сердце → розовое, препятствия → янтарный варнинг, капча
  → циан-панель. Игрок остался красным (теперь контрастирует, а не сливается).
- **Капча-фикс**: эмодзи заменены на **векторные draw-функции** (`ICONS` в
  `captcha.js`) — рисуются примитивами Canvas, работают везде и детерминированно.
- **Спрайты**: `assets/manifest.json` очищен до `[]` — игра рендерится полностью
  процедурно, live совпадает с preview. PNG-файлы оставлены в репозитории; чтобы
  вернуть спрайт-слой, нужно перегенерить их под мульти-хью палитру и вписать ключи
  обратно в манифест.
- **UI** (`style.css`): фон меню/геймовера, циан-сетка и закатное солнце; дистанция
  в HUD — циан-акцент. Share-карта (`sharecard.js`) переведена в закатную гамму.

## Prevention
- Любой новый визуальный элемент берёт цвет из `CONFIG.COLORS` по семантическому
  ключу — НЕ хардкодь красный `rgba(255,41,55,…)` по месту.
- **Никаких эмодзи в canvas** (`font:'system-ui'`/любой) — нет гарантии эмодзи-шрифта
  в WebView/офлайн-рендере. Только текст брендовым `FONT` или векторные примитивы.
- Спрайты должны соответствовать активной палитре; при смене палитры — либо
  перегенерить ассеты, либо очистить манифест (см. также
  `2026-06-08-revert-ai-assets-procedural-rendering.md`).
- После визуальных правок: `npm test` + `npm run shots` и сверка `preview/*.png`
  глазами (офлайн-рендер не грузит спрайты — это и есть «чистый» процедурный кадр).
