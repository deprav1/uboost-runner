# План улучшений «ЮБуст Раннер»

Дата: 2026-06-10. Основан на аудите кода (main.js, world.js, events.js, strings.js,
sharecard.js, screens.js, config.js, index.html).

Цели по приоритету: (1) игра живёт в Telegram как родная и не теряет игроков из-за
технических мелочей, (2) игрок хочет вернуться и пошарить результат, (3) воронка на
VPN конвертит, (4) визуал и мемы усиливают первые три пункта.

---

## Фаза 1. Telegram Mini App — критичные фиксы (1–2 дня)

Самое дешёвое по трудозатратам и самое большое влияние на удержание.

### 1.1 `disableVerticalSwipes()` — КРИТИЧНО
Игра управляется свайпами, а в Telegram свайп вниз сворачивает мини-апп — игрок
вылетает посреди забега. Вызвать `tg.disableVerticalSwipes()` (Bot API 7.7+) и
`tg.isVerticalSwipesEnabled` рядом с существующими `tg.ready()/tg.expand()`
в `src/main.js:37-40`.

### 1.2 CloudStorage для рекордов
Сейчас рекорд только в `localStorage` (`src/game/stats.js`), а Telegram WebView
может чистить storage. Добавить в `stats.js` асинхронную синхронизацию через
`tg.CloudStorage.getItem/setItem('best')` с localStorage как кэшем/фолбэком.
Инвариант: игра обязана работать вне Telegram без изменений (фолбэк уже есть).

### 1.3 Цвета шапки и фона
`tg.setHeaderColor('#000000')` + `tg.setBackgroundColor('#000000')` — сейчас шапка
TG может быть светлой и разрывать синтвейв-атмосферу. Тему игры под светлую тему TG
НЕ адаптируем — игра намеренно тёмная, фиксируем чёрный.

### 1.4 `viewportChanged`
Подписаться на `tg.onEvent('viewportChanged', ...)` → дёргать существующий resize
канваса (`src/engine/render.js`). Сейчас при выезде клавиатуры/смене viewport канвас
может остаться неправильного размера.

### 1.5 Deep-link «вызов друга» (фундамент виральности)
- При шеринге добавлять `?startapp=<score>` (или `start_param` через бота) к ссылке.
- При запуске читать `tg.initDataUnsafe.start_param` → если есть счёт вызова,
  показать на стартовом экране плашку «Тебя вызвали: побей N очков» и в HUD —
  отметку цели. Побил → отдельный гэг «ВЫЗОВ ПРИНЯТ» + предложение перешарить.
- Файлы: `src/main.js` (парсинг), `src/ui/screens.js` (плашка), `src/ui/strings.js`
  (копирайт), `config.js` (флаг).

Это превращает шеринг из «похвастаться» в петлю: вызов → побил → вызвал в ответ.

## Фаза 2. Retention — чтобы возвращались (2–4 дня)

### 2.1 Миссии за сессию (3 шт.)
Простые цели, видны на стартовом экране: «собери 50 битов», «реши 2 капчи»,
«пролети 1000 м без потери жизни». Выполнение → бонус к стартовым очкам или
+1 жизнь на следующий забег. Хранить прогресс в `stats.js` (localStorage +
CloudStorage). Новый модуль `src/game/missions.js`, тексты — в `strings.js`,
константы — в `config.js`.

### 2.2 Новые пикапы-баффы (по одному, поэтапно)
Сейчас три пикапа (бит/сердце/буст) — мало вариативности. Добавить в
`src/game/collectibles.js` по образцу существующих классов:
- **Магнит** (10 сек): биты с соседних полос притягиваются — приятный «pop-corn» фидбек.
- **x2 очки** (15 сек): множитель в `stats.js`, индикатор в HUD рядом с boost-баром.
Спавн — через существующую логику колонн в `spawnColumn()` (`src/main.js:134`).

### 2.3 Волны сложности вместо линейной прогрессии
Сейчас `diffNow()` линейная → монотонно. Сделать в `config.js` синусоидальную
надбавку: 20–30 сек нарастание → 8–10 сек «передышка» с щедрым спавном битов
(мини-«бонус-раунд»). Игрок чувствует ритм, передышка = момент выдоха, который
заставляет играть «ещё одну».

### 2.4 Достижения-бейджи (лайт-версия)
5–8 бейджей («Антиробот» — 10 капч, «Неуловимый» — 50 near-miss, «Марафонец» — 5000 м).
Показывать на game over + на шеринг-карточке (см. 4.2). Без бэкенда — localStorage/CloudStorage.

## Фаза 3. Визуал — точечные усиления (2–3 дня)

База уже сильная (bloom, частицы, параллакс, adaptive quality) — не переделывать,
а добивать читаемость и «сочность». Все эффекты — с учётом тиров `quality.js`
(на тире 0 новые эффекты выключены).

### 3.1 Цветные частицы по типу препятствия
В `handleCollisions` (`src/main.js:182`) передавать цвет типа (`TYPES[type].color`
из `obstacles.js`) в `particles.burst()` — смэш РКН янтарный, капчи циановый.
Дёшево, заметно.

### 3.2 Анимация препятствий
- Реклама: бегущая строка текста в окне (сдвиг по `t`), уже есть мигание.
- РКН: покачивание замка ±рад по sin(t).
- Лаг: «джиттер» позиции ±1–2px (уже частично есть дрожание — усилить).
Всё в `draw()` соответствующих типов в `src/game/obstacles.js`.

### 3.3 Смена «зон» по дистанции (палитра)
Каждые ~1500 м плавный сдвиг hue фона/сетки (фиолет → циан-ночь → красная «зона
блокировок»). Реализация: lerp базовых цветов в `world.js` по `distance`, цвета зон —
в `config.js COLORS`. Даёт ощущение прогресса «куда-то лечу», главный ответ на
«монотонно после 2 минут».

### 3.4 HUD-анимации
Счёт «дотикивает» к значению (lerp в `screens.js`, уже есть троттлинг 80ms —
встроиться в него), комбо-лейбл пульсирует при инкременте (CSS-анимация в
`style.css`, класс вешать из `screens.js`).

### 3.5 Смерть по типу врага
Сейчас флеш однообразный. Цвет вспышки и текст частиц — по убившему типу
(янтарный глитч у РКН, мигающий «ЖМИ» у рекламы). `main.js` (переход в `dying`)
+ `particles.js`.

После каждого визуального изменения: `npm run shots` + сверка `preview/*.png`.

## Что НЕ делаем (осознанно)

- **Лидерборд с бэкендом** — требует сервер/бота, противоречит «без билда и
  зависимостей». Челлендж через start_param (1.5) даёт 80% эффекта бесплатно.
- **TypeScript/фреймворки/бандлер** — запрещено правилами репо.
- **Светлая тема** — игра тёмная by design.
- **Спрайт-анимации/ассеты** — процедурный рендер остаётся основой (история в
  `docs/solutions/2026-06-08-revert-ai-assets-procedural-rendering.md`).
